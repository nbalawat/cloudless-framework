# cloudless brand assets

Drop-in assets and guidelines for the `cloudless` brand.

## Contents

- `guidelines.md` — colors, typography, voice & tone, do/don't
- `colors.json` — design tokens (consumed by mkdocs `extra.css`)
- `logos/` — three SVG logo concepts + chosen final
- `favicons/` — favicon set (16, 32, 180, 512)
- `social/` — Open Graph + Twitter Card images
- `copy.md` — marketing copy (tagline, blurbs, pitches)

## Quick reference

| Token        | Value     | Usage                      |
|--------------|-----------|----------------------------|
| `--ink`      | `#0F1B2D` | Primary text on light bg   |
| `--mist`     | `#E8EEF5` | Paper / page background    |
| `--spark`    | `#FF5C39` | CTA, accent, link hover    |
| `--sky`      | `#3B82F6` | Secondary accent, info     |
| `--slate`    | `#475569` | Body text                  |
| `--paper`    | `#FFFFFF` | Card background            |

Typography: Inter (display + body), JetBrains Mono (code).

The brand name is **always lowercase**: `cloudless`.
Never `Cloudless`, never `CLOUDLESS`, never `CloudLess`.
