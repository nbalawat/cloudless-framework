# Getting started

cloudless is a Python framework. If you can install a package and run a CLI,
you can have an agent deployed to AWS or GCP in under five minutes.

1. [**Install**](install.md) — pick the cloud + framework extras you need
2. [**Quickstart**](quickstart.md) — run `cloudless init` → `dev` → `deploy`
3. [**Your first agent**](first-agent.md) — author a real agent from scratch

If you hit a snag, run `cloudless doctor` first. It checks every common
hazard (AWS creds, inference profiles, Anthropic streaming gates, Python
version, GCP ADC, etc.) and points you at the fix.
