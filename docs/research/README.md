# Research dossiers

These five reports were commissioned during the architecture interview (2026-05-14) to ground every design decision in current cloud-platform reality. Each was generated by a research agent that pulled from official docs, blog posts, GitHub repos, conference talks, and third-party analysis, with URLs cited inline.

Together they cover everything cloudless's design depends on:

1. [**AgentCore Runtime deep dive**](./01-agentcore-runtime.md) — what AWS's managed agent runtime is, deployment model, runtime contracts (HTTP/MCP/A2A/AG-UI), session model, scaling, pricing, limits, gotchas.
2. [**AgentCore primitives**](./02-agentcore-primitives.md) — Memory, Identity, Gateway, Code Interpreter, Browser, Observability. Each one's API surface, cloud portability, pricing, and gotchas.
3. [**AgentCore + frameworks + A2A**](./03-agentcore-frameworks-and-a2a.md) — how Strands / LangGraph / Google ADK / MS Agent Framework integrate with AgentCore; current state of A2A protocol; cross-cloud auth patterns.
4. [**AgentCore vs Vertex AI Agent Engine**](./04-agentcore-vs-vertex-agent-engine.md) — side-by-side comparison across deployment, runtime contract, framework support, session model, memory, identity, tools, sandbox, browser, observability, A2A, pricing, limits, maturity. Identifies impedance mismatches the abstraction must absorb.
5. [**Gemini Enterprise rebrand**](./05-gemini-enterprise-rebrand.md) — Vertex AI was rebranded to Gemini Enterprise Agent Platform at Google Cloud Next '26 (April 22, 2026). Captures what changed, what didn't, what's new (Agent Identity / Gateway / Sandbox / Registry / Observability), and the hard SDK migration deadline (June 24, 2026).
6. [**AgentCore canonical architecture**](./06-agentcore-canonical-architecture.md) — User-provided AWS architecture diagram, 2026-05-14. Source-of-truth on what AgentCore actually offers: 8 primitives (incl. Payments + Knowledge Bases + Search + Registry-with-MCP-and-skills), 3 entry points (Harness + CLI + SDK), and the Build/Deploy/Assess lifecycle. Supersedes dossiers 01 + 02 where they diverge.
7. [**Gemini Enterprise canonical architecture**](./07-gemini-enterprise-canonical-architecture.md) — User-provided official Google diagram, 2026-05-14. The Build / Scale / Govern / Optimize pillars with 21 sub-primitives. Adds: A2UI (agent-to-UI), Agent Optimizer (auto-refinement), Cloud Marketplace integration, separate Anomaly Detection / Compliance / Security primitives. Cross-cloud parallel primitive map included. Supersedes dossier 05 where it diverges.

## Reading order

If you're new to this design and have an hour:
1. Read [`../ARCHITECTURE.md`](../ARCHITECTURE.md) first for the synthesized decisions.
2. Then `04-agentcore-vs-vertex-agent-engine.md` for the cross-cloud lay of the land.
3. Then `05-gemini-enterprise-rebrand.md` for what's true on GCP today (post-rebrand).
4. Then `01-agentcore-runtime.md` + `03-agentcore-frameworks-and-a2a.md` for the AWS-side depth.
5. `02-agentcore-primitives.md` is a reference — dive in when designing a specific primitive's adapter.

## Staleness

Each report is dated. Cloud platforms move fast. Re-validate any specific claim before relying on it for implementation — especially:

- AgentCore protocol contracts (AWS may add multi-protocol per runtime, which would change Q6 in [`../DECISIONS.md`](../DECISIONS.md))
- Memory pricing on either cloud
- Framework support tiers (MAF could get first-party adapters; ADK could ship `AgentCoreMemorySessionService`)
- A2A protocol version on AgentCore (currently shows 0.3.0 in samples; spec is v1.2)
